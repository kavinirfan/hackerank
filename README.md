# 🧠 FacePrep — Python Problem Solving

A collection of coding problems solved during **FacePrep coding sessions**, using **Python** as the programming language.

The primary focus of these sessions is **problem-solving, logical thinking, and developing the ability to approach coding problems** rather than learning Python from scratch.

## 🎯 Objective

This repository is created to document and practice problems covered during the sessions and to improve:

* 🧠 Logical thinking
* 💡 Problem-solving skills
* 🔍 Understanding problem statements
* 🧩 Breaking problems into smaller steps
* 📝 Converting logic into code
* ⚡ Developing efficient solutions
* 🎯 Preparing for coding assessments and placement tests

## 💻 Language

**Python 🐍**

Python is used to implement the solutions. The main focus, however, is on **understanding the problem and developing the correct logic**.

## 🧩 Problem-Solving Approach

For each problem, the general approach is:

```text
Problem Statement
       ↓
Understand the Problem
       ↓
Identify Inputs & Outputs
       ↓
Analyze the Requirements
       ↓
Develop the Logic
       ↓
Create an Algorithm
       ↓
Implement in Python
       ↓
Test the Solution
       ↓
Optimize if Required
```

## 📚 Topics & Problem Types

Problems covered throughout the sessions may include:

* Conditional logic
* Loops
* Arrays / Lists
* Strings
* Mathematics
* Searching
* Sorting
* Algorithms
* Pattern-based problems
* Logical problems
* Optimization
* Input / Output handling
* Problem-solving techniques

## 🎯 Goal

The goal of this repository is not simply to collect Python programs, but to build the ability to **understand, analyze, and solve programming problems independently**.

> **Python is the tool. Problem-solving is the skill.**
